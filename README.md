# TelegramPoll-AAC

**Telegram Poll Bot / Utility** for creating and managing polls in Telegram.

## 🧾 Overview

TelegramPoll-AAC is a bot/tool that allows you to create polls (or questionnaires) in Telegram chats or groups.  
It simplifies the process of gathering responses from users — whether for votes, feedback, quizzes, or group decisions.

## ✨ Features

- Create polls in Telegram chats or groups  
- Support for multiple choices or single-choice polls (depending on implementation)  
- Handles user votes / responses automatically  
- (Optional) Configuration for poll parameters (anonymous vs non-anonymous, options, durations, etc.)  
- Easy deployment — minimal dependencies (see Requirements)  
- Ideal for communities, groups, teams, or any scenario needing collective decision or feedback

## ✅ Requirements / Prerequisites

- A Telegram Bot Token (get from @BotFather)  
- Programming runtime (Java)  
- Internet connection (to interact with Telegram API)  
- (Optional) Hosting environment if you want the bot always online (server, cloud, VPS, etc.)
